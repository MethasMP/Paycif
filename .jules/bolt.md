## 2026-08-07 - Optimization of IP Prefix Containment and Parsing with net/netip
**Learning:** Standard library `net.IP` and `net.IPNet` (legacy IP types in Go) perform slice allocation and pointer indirection overhead, especially on hot paths like IP range containment checks in cloudflare geoblocking or geofencing filters. The modern `net/netip` package, introduced in Go 1.18, defines IP addresses and prefixes as value types (allocation-free structs with no internal pointers), significantly lowering processing latency and avoiding heap allocations.
**Action:** Always prefer `net/netip` (`netip.Addr`, `netip.Prefix`) instead of `net.IP`, `net.IPNet`, `net.ParseIP`, and `net.ParseCIDR` for all IP-based parsing, comparison, and subnet containment hot paths to eliminate heap memory footprint and achieve up to ~1.64x speedup.
